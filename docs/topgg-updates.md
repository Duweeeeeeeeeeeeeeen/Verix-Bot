# Top.gg Update Templates

Use these short formats when publishing updates on Top.gg. Keep them concrete and focused on what server owners can try immediately.

## Standard Update

**Verix Update - [version/date]**

We improved [module/area] with [main change].

What's new:
- [User-facing improvement]
- [Bug fix or stability improvement]
- [Dashboard or configuration improvement]

Try it from the Verix dashboard: https://verixbot.com

## Stability Update

**Verix Stability Update**

This update focuses on reliability and smoother server management.

Highlights:
- Improved [module] stability.
- Fixed [specific broken behavior].
- Refined dashboard configuration for [area].

Thanks for using Verix and helping us make it better.

## Feature Update

**New in Verix: [feature name]**

Verix now supports [feature] for communities that need [use case].

You can configure it from the dashboard under **[module name]**.

Highlights:
- [Capability 1]
- [Capability 2]
- [Capability 3]

Open the dashboard: https://verixbot.com
